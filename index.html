Step-by-Step Data Flow

01
External data ingestion
Economic calendar APIs (Investing.com, Trading Economics, FRED) push scheduled event metadata into the ingestion layer on a 15-minute polling cycle or via webhook on event release. FX price feeds (Twelve Data, Alpha Vantage, or a broker WebSocket) stream tick and OHLC data in real-time. Volatility, sentiment, and central bank data are fetched on daily or per-event schedules.
02
Processing layer transforms raw data
The Event Processor computes surprise_magnitude = (actual − forecast) / historical_std_dev at release. The Price Impact Engine applies: expected_move_pips = surprise × sensitivity × session_multiplier. The Volatility Calculator derives ATR and IV regime flags. The Sentiment Scorer runs NLP classification (bullish / bearish / neutral) and blends with the quantitative surprise. All output is normalised and UTC-timestamped before storage.
03
Data written to storage
Time-series price and vol data writes to a time-series DB (InfluxDB / TimescaleDB). Event metadata writes to a relational store (PostgreSQL). Player state and session data write to a fast key-value store (Redis) for low-latency access during gameplay. Historical event archives support the replay engine with pre-computed outcomes.
04
Simulation engine consumes stored data
On event countdown start, the engine reads the scheduled record and begins a visual countdown. At T=0 the engine reads the processed surprise value, queries the impact model, and applies a simulated price move. Player orders are received by the Trade Order Handler; the P&L Calculator settles each trade with spread plus slippage; the Risk Manager enforces SL/TP and margin rules. In replay mode, the Replay Engine substitutes historical data for live feeds.
05
Results surface in the presentation layer
The live price chart updates from the simulation engine's internal tick feed. The news event panel displays event name, forecast, actual, and surprise magnitude. The trade blotter shows open and closed positions with real-time P&L. At session end, the leaderboard updates from the scoring store.
06
Educational feedback layer closes the loop
Post-trade debrief compares player direction and timing against the optimal response from the price impact model. Reaction time, directional accuracy, and risk/reward are scored and logged. Bias detection flags systematic patterns (always fading the trend, always exiting early). Skill progression unlocks new instruments and higher-tier events. All session data writes back to the player store, closing the feedback loop to Layer 4.
